Scope & Modes

Applies to any new image or video generation model being trialed against the current production baseline (currently Gemini Imagen/Nano Banana for image, Veo for video). Run this framework any time a candidate model is added to UAT.

Test each mode separately — a model can be strong at one and weak at another, and VizAI uses all four.

ModeDefinition
Image createText-to-image, no input reference
Image augmentImage-to-image — editing/extending an existing render, map, or photo
Video createText-to-video, no input reference
Video animateImage-to-video — animating an existing still (e.g. render fly-through)

Evaluation Criteria

Weight quantitative and qualitative equally — a model that scores well qualitatively but is too slow or expensive for production use isn't a viable candidate, and vice versa. Treat faithfulness / constraint-holding (geometry preservation, staying within a given edit boundary) as its own axis, separate from general surface quality — the two do not track together (see Key Findings).

Key Findings So Far (5 augment tests)

gpt-image-2 is the clear faithfulness leader. Clean across every test run — geometry held in all 4 relevant tests, materials executed correctly, signage stayed legible, and it's the only model to pass the constrained zoom test (Test 5). This is the quality ceiling, at a consistent cost: slowest every time (39–44s) and among the largest files.
gpt-image-1.5 has a real, repeated geometry problem. Strong on materials, lighting, and atmosphere, but failed geometry preservation in 3 of 4 relevant tests (Test 1 cantilever drift, Test 3 podium geometry wrong, Test 4 podium changed again) and also failed the constrained zoom test. This is a consistent pattern, not noise — worth treating as a production risk if geometry fidelity matters. Caveat: one run per test; worth re-confirming with a repeat run before this goes into a formal report.
Gemini Nano Banana 2 holds geometry and materials well, but takes more creative liberty on unconstrained details (invented screen content, different crowd density) and had the clearest failure on the constrained zoom test (generated an unrelated building entirely).
Gemini Nano Banana Pro sits just behind gpt-image-2 on general fidelity, best lighting/shadow match in Test 1, but also failed the zoom constraint and tends toward tighter/cropped compositions than the source.
Gemini Nano Banana 2 Lite is the speed/size outlier — 3–5x faster than everything else, files often 10x smaller — but that consistently costs material and edge fidelity, and it only partially passed the zoom test.
Overall quality and constraint-holding are separate skills. Models that scored well on surface quality (gpt-1.5, Nano Banana Pro) failed to hold an explicit "don't redesign this" instruction, while quality wasn't a reliable predictor of faithfulness. Score these as genuinely separate criteria in the Decision Framework, not one blended number.

Scoring Method

  • Score each output 1–5 per criterion (5 = production-ready, 1 = unusable).
  • Run blind where possible — reviewer shouldn't know which model produced which output, to avoid bias toward the incumbent.
  • Minimum 2 reviewers per test set, scores averaged.
  • Record raw outputs + scores in one sheet (per model) so runs are auditable later.

Decision Framework

Score per mode, not just per model overall — a model can be worth integrating for image augment only, for example.

A mode/model combination is a candidate for production integration if it:

  • Matches or beats baseline on qualitative criteria average
  • Matches or beats baseline on success rate and artifact rate
  • Is neutral-or-better on speed and cost, OR the qualitative gain justifies the delta
  • Holds constraints reliably on augment tasks (not just surface quality)

Otherwise: park it, note why, revisit at next model refresh.

Output Template (per model, per mode)

  • Model name / version
  • Mode tested (create / augment / animate)
  • Date tested
  • Avg qualitative score per criterion
  • Success rate, retry rate, artifact rate
  • Avg generation time
  • Avg cost per generation
  • Output resolution / duration / fps (as applicable)
  • Reviewer notes — what it's good/bad at
  • Recommendation: Integrate / Park / Retest

Cost-Performance Takeaways
Budget production tier ($0.030–$0.035/gen): Qwen Image 3, Seedream 5.0 Lite, gpt-image-2, and Nano Banana 2 Lite offer the lowest per-gen cost. Of these, gpt-image-2 delivers the highest geometry fidelity and constraint-holding while Nano Banana 2 Lite is the fastest (8s) but lowest quality.

Value frontier ($0.047–$0.050/gen): Microsoft MAI-Image-2.5 ($0.047, 29.7s) and Grok Imagine Image 2.0 ($0.050, 10.7s) are benchmark standouts — MAI-Image-2.5 provides superior spatial constraint holding (passing Test 5 cleanly) and impeccable architectural materials, while Grok Imagine 2.0 delivers blistering real-time speed.

Quality & Fidelity Ceiling ($0.070–$0.108/gen): Microsoft MAI-Image-2.5 Pro ($0.108, 41.6s) and FLUX.2 Max ($0.070, 33.0s) represent the highest tier of photorealistic realism, pristine geometry holding, atmospheric mood swaps, and complex zoom constraints.
